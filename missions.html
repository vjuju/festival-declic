Encadrement autowash

⛲ Fonctionnement de l'autowash

4 lignes :

  • 1 ligne allday — Tasses, verres et écocups uniquement (3 bacs)
  • 3 lignes — Toute la vaisselle (4 bacs par ligne)

Les différents bacs :

  • 0 : poubelle pour jeter les restes
  • 1 : bac eau chaude + liquide vaisselle : enlever le gras
  • 2 : bac eau chaude + liquide vaisselle : laver la vaisselle
  • 3 : bac eau vinaigre : 1er rinçage pour désinfecter
  • 4 : bac eau froide : 2nd rinçage

📜 Détail de la mission

  • Se répartir en 1 personne par ligne
  • S'assurer que les personnes lavent bien leur vaisselle
  • Ré-expliquer l'ordre des bacs si besoin
  • Faire la vaisselle oubliée (à côté ou dans les bacs)

Quand c'est trop sale, on change les bacs !

On procède ligne par ligne pour avoir toujours 2 lignes en fonctionnement pour éviter les bouchons :

  • On vide le bac 1, on le lave, puis on le remplit d'eau froide + vinaigre
  • Le bac 2 prend la place du bac 1 > On ajoute du liquide vaisselle dedans
  • Le bac 3 prend la place du bac 2

On prend une bouilloire pour ajouter de l'eau chaude et réchauffer les nouveaux bacs 1 et 2 (attention à avoir une eau tiède/chaude mais pas brûlante).

📍 On se retrouve où ? Coin Eautowash

🖐 Personne référente : Angèle & Ulysse

Approvisionnement Zone Petit creux

📜 Détail de la mission en fonction de l'horaire

➔ Zone Petit Creux 1 (Matin)

  1. Compléter le nombre de tasses et verres (aller les chercher à l'autowash / finir de les sécher si besoin)
  2. Compléter le sucre et les laits végétaux
  3. Aller chercher en cuisine : les fruits et les condiments pour l'eau aromatisée
  4. Préparer les boissons fraîches (eaux aromatisées)
  5. Préparer le set Petit Creux

➔ Zone Petit Creux 2 (Midi)

  1. Préparer 3 percolateurs : café, kofé 532, tisane ! Commencer par ça
  2. Quand les percolateurs sont prêts, remplir les thermos
  3. Relancer 3 percolateurs : café, kofé 532, tisane !
  4. Aller chercher en cuisine : les fruits et les condiments pour l'eau aromatisée
  5. Compléter les eaux aromatisées
  6. Regarnir les fruits
  7. Compléter les tasses et verres
  8. Compléter le sucre et les laits végétaux
  9. Regarnir le set petit creux

➔ Zone Petit creux 3 (Goûter)

  1. Compléter les tasses et verres
  2. Compléter le sucre et les laits végétaux
  3. Préparer le set gros goûter (Cookies…)
  4. Aller chercher en cuisine : les fruits et les condiments pour l'eau aromatisée
  5. Compléter les eaux aromatisées
  6. Regarnir les fruits

➔ Zone Petit Creux 4 (Fin d'aprem)

  1. Compléter les verres
  2. Aller chercher en cuisine : les fruits et les condiments pour l'eau aromatisée
  3. Compléter les eaux aromatisées
  4. Regarnir les fruits
